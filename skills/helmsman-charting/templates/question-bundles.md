# Question Bundles

## Rules

- Ask at most 4 questions per bundle.
- Bundle count is unlimited across Charting.
- Every question must change the route if answered differently.
- Each question must include A/B/C options by default.
- Each option must include `Reason`, `Tradeoff`, and `What this answer changes`.
- Exactly one option should be marked `(Recommended)` unless the bundle explicitly records why no recommendation is safe.
- Free-form correction is allowed.
- Native chat is the question surface; artifact existence is not proof that the bundle was asked.
- Rendered or answered bundles must cite `evidence/native-chat-transcript.jsonl#<message-id>` records for the assistant-rendered question surface and, once answered, the user answer.
