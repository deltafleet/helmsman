# Stop Conditions

Stop and leave a resume packet if any of these occur:

- The native goal conflicts with the attached Goal Charter.
- The route promise cannot be advanced by the current action.
- A product, scope, destructive, credential, release, or competitive-claim decision requires user authority.
- Verification evidence is unavailable or contradicts the completion claim.
- The agent would need to invent a new goal, rewrite the autonomy boundary, or continue outside `contract.md`.

Do not convert a stop condition into an implementation task. Preserve the state and ask the user to decide.
